# Формализованные правила «За бортом»

**Единственный источник истины** по игровой логике. Любая реализация должна соответствовать этому документу. При расхождении с физическим PDF правил — обновляется этот файл (после обсуждения), реализация подстраивается. При расхождениях между этим документом и кодом — обновлять и то, и другое.

## 1. Обзор / параметры

- **Игроков:** 4–6
- **Цель:** набрать максимум очков к моменту, когда лодка причалит к берегу (накопится 4 жетона чаек) или когда никто не выживет.
- **Длительность партии:** ~40 минут
- **Жанр:** социальная игра с переговорами, скрытой информацией и блефом.
- **Бот может занять место** игрока, если живых < 4 (см. [`docs/bots.md`](./bots.md)).

Ход = «день» из 3 фаз:

1. **Утро** — раздача припасов
2. **День** — действия игроков
3. **Вечер** — навигация (раскрытие карты, последствия)

Игра кончается, когда выпала 4-я чайка, после чего идёт фаза подсчёта очков. Если все мертвы до 4 чаек — море побеждает, очки не считаются.

### 2.2 Карты припасов (42 штуки)

Категории:

- **Спасательные:** вода (одноразовая), аптечка (одноразовая), зонтик (многоразовый), сигнальный пистолет (одноразовый), спасательный круг (многоразовый), компас (многоразовый)
- **Гребля и оружие:** весло (универсальное — гребля или оружие), дубинка, багор, нож (оружие, многоразовое в драке)
- **Спецэффект:** приманка для акул (одноразовая, вечером)
- **Ценности:** деньги, украшения, картины — карты с конкретными очками

| Тип | Использование | Прим. количество[^1] |
|---|---|---|
| `water` | Защищает от 1 раны от жажды, одноразовая, применяется в любой момент | ~6 |
| `first_aid` / `firstAid` | Снимает 1 рану с себя или другого, одноразовая, **только днём в свой ход** | ~4 |
| `umbrella` | Лежит открытой, защищает владельца от ран от жажды, тонет при падении за борт. Открывается **только днём в свой ход** | ~2 |
| `flare_gun` / `flare` | Одноразовая, **только днём в свой ход как отдельное действие**. Открыть верх колоды навигации на 3 карты, посчитать только чайки (добавить/убрать жетоны), затем убрать карты под колоду | ~2 |
| `compass` | Многоразовая, работает у игрока ближайшего к корме и в сознании, должна быть открыта. Даёт +1 карту навигации при вечернем выборе | ~2 |
| `life_ring` / `lifeRing` | Открытый защищает владельца (или указанного игрока) от падения за борт. Можно открыть в момент падения. Спасает даже мёртвых и без сознания | ~2 |
| `oar` (весло) | Либо +1 к силе в драке, либо +1 карта при действии «Погрести» (можно 2 весла → +2 карт). Можно передавать. Многоразовое | ~4 |
| `shark_bait` / `sharkBait` (приманка) | Одноразовая, **только вечером после раскрытия карты навигации**. Все, кто за бортом, получают +1 рану (включая владельца, если он сам за бортом из-за открытых припасов) | ~2 |
| `club` (дубинка) | Оружие, +N силы в драке (по карте) | ~2 |
| `hook` (багор) | Оружие, +N силы в драке (обычно +4) | ~2 |
| `knife` (нож) | Оружие, +N силы в драке | ~2 |
| `money` (пачка денег) | Очки при подсчёте (1/3/5 на разных картах), x2 у Капитана | ~3 |
| `jewelry` (украшения) | Очки при подсчёте (часто 3), x2 у Миледи | ~3 |
| `painting` (картина) | Очки при подсчёте (2 или 3 на разных картах), x2 у Сноба | ~3 |

### 2.3 Карты навигации (24 штуки)

Каждая карта состоит из 3 секций:

- **Верх (чайка)**: чайка / перечёркнутая чайка / ничего
- **Середина (за борт)**: список персонажей, которые падают за борт, или пусто (или `all`)
- **Низ (жажда)**: список персонажей, страдающих от жажды, или иконки `вёсла`/`силач`/пусто

Структура (два варианта типизации — выбрать один):

```ts
// Вариант A (01-rules-formalized.md / 02-game-spec.md):
{
  seagull: 'none' | 'normal' | 'crossed',
  overboard: CharacterId[] | 'all' | 'none',
  thirst:
    | { type: 'characters'; list: CharacterId[] }
    | { type: 'rowers' }
    | { type: 'fighters' }
    | { type: 'none' };
}

// Вариант B (game-rules.md / game-spec.md):
{
  id: NavCardId;
  seagulls: 0 | 1 | -1;             // 0=нет, 1=чайка, -1=перечёркнутая
  overboard: Character[];            // имена сверху карты
  thirst:
    | { kind: 'named'; characters: Character[] }
    | { kind: 'rowers' }
    | { kind: 'fighters' }
    | { kind: 'rowers+named'; characters: Character[] }
    | { kind: 'fighters+named'; characters: Character[] }
    | { kind: 'none' };
}
```

> **Open question: представление эффекта чаек.**
> Версия A — строковый enum `'none' | 'normal' | 'crossed'`. Версия B — числовой `-1 | 0 | 1` (удобно складывать). Логика одинаковая.

> **Open question: триггер жажды.**
> Версия A разделяет `characters` / `rowers` / `fighters` как взаимоисключающие. Версия B добавляет комбинированные `rowers+named` и `fighters+named`. На физических картах эффекты могут суммироваться, поэтому B выглядит точнее, но требует комбинированных вариантов в коде.

### 2.4 Жетоны и геометрия

- **24 жетона ран** (`Wound`) — накапливаются на персонаже
- **12 двусторонних жетонов усталости** (`Fatigue`): стороны `rower` («вёсла») и `fighter` («силач»)
- **4 жетона чаек** (`SeagullToken`) — выкладываются на корму
- **Банки лодки (`Seat`)**: фиксированные позиции в лодке (см. ниже)
- **Нос (`Bow`)** — место для колоды припасов
- **Корма (`Stern`)** — место для колоды навигации + жетоны чаек + карты от гребцов

#### Геометрия лодки

Лодка — упорядоченная последовательность `Seat[]` от носа к корме. Для 6 игроков: 6 банок; для 5: 5; для 4: 4. **Порядок ходов = порядок банок от носа к корме.**

Визуально можно расположить как угодно (две колонки по 3, ряд из 6, и т.д.), но **логически это упорядоченный массив**.

- На MVP: модель «банки в линию», `seats[0]` ближе к носу, `seats[N-1]` ближе к корме.
- Player-to-seat mapping: каждый player сидит на одной банке (где лежит его персонаж).
- При свопе мест — меняются местами карты персонажей на банках, но не меняются player IDs за этими картами.

Каждая банка хранит:

```ts
{
  index: number;                 // 0..n-1, 0 = нос
  occupantId: PlayerId | null;   // null если игрок мёртв и убран
  // (вариант A добавляет removed: boolean для удалённых при 4/5 игроков)
}
```

### 2.5 Карты ролей / друзей / врагов (по 6 штук каждой колоды)

- **Карта роли** = карта персонажа (раздаётся в открытую): `{ character, strength, survivalBonus, ability }`.
- **Карта лучшего друга** — какой персонаж ваш друг (приватно). Если выпал сам себе — игрок «нарцисс».
- **Карта заклятого врага** — какой персонаж ваш враг (приватно). Если выпал сам себе — игрок «психопат».

Возможно совпадение «вы сами себе друг» (нарцисс) или «вы сами себе враг» (психопат).

При **5 игроках** один случайный персонаж изымается из колод (роли, друзья, враги, банка). При **4 игроках** — два.

## 3. Подготовка

### 3.1 Стандартная подготовка

1. Перемешать 6 карт ролей, раздать по одной каждому игроку **в открытую**.
2. Перемешать 6 карт друзей, раздать по одной каждому **в закрытую**.
3. Перемешать 6 карт врагов, раздать по одной каждому **в закрытую**. Каждый смотрит свои секретно.
4. Выложить нос, корму, банки между ними. Положить карты персонажей на банки в порядке банок (порядок банок фиксирован).
5. Перемешать припасы, раздать каждому по 1 карте **в закрытую**.
6. Положить оставшуюся колоду припасов на нос.
7. Перемешать карты навигации, положить на корму.
8. Жетоны (чайки, усталости, ранений) разложены рядом.

**Случайность.** Все перетасовки — через сидированный RNG, чтобы партии были воспроизводимы.

### 3.2 Игра на 5 игроков

Перед началом случайным образом выбрать одного персонажа и убрать его из всех колод (роли, друзья, враги) и убрать его банку из лодки.

После раздачи карт может оказаться, что чей-то друг/враг — отсутствующий персонаж. Это нормально: **«упоминания о нём игнорируются»**.

### 3.3 Игра на 4 игроков

То же самое, но убрать **двух** случайных персонажей.

### 3.4 Boat order

Карты персонажей раскладываются на банках. Банки имеют фиксированный порядок: от носа к корме. Этот порядок и определяет boat order — порядок ходов в текущем дне.

## 4. Структура хода

Один ход = один день. Состоит из 3 фаз: **утро → день → вечер**. После вечера — следующее утро (или конец игры, если 4 чайки).

## 5. Фаза «Утро» — раздача припасов

**Условие пропуска:** если колода припасов пуста — пропустить, перейти сразу к Дню.

```
players_in_consciousness = живые и в сознании, в порядке банок от носа
if колода припасов пуста → пропустить фазу, перейти к Дню
N = len(players_in_consciousness)

starter = ближайший к носу из players_in_consciousness
deal N supplies from deck (закрыто)

for player in players_in_consciousness (in seat order from starter):
  if player == last:
    player получает последнюю карту автоматически
  else:
    player выбирает 1 из текущей пачки, кладёт перед собой закрыто
    оставшиеся передаёт следующему по очереди
```

**Важно:**

- Мёртвые и без сознания пропускаются (не считаются в N, не получают карт).
- Порядок передачи — строго по boat order, физическое расположение игроков иррелевантно.
- В закрытую — значит видна только владельцу. Карта попадает в `closedSupplies`.

> **Open question: если в колоде припасов < N карт утром, как делить?**
> В PDF про это не сказано явно.
> Предлагаемая трактовка: раздавать сколько есть, в порядке цепочки; кто не получил — не получил. Цепочка пересчитывается; последний берёт что осталось.

## 6. Припасы — общие правила

- Хранятся **открытыми** (face-up, перед игроком, все видят) или **закрытыми** (face-down). Однажды открытая карта **не может быть закрыта обратно**.
- Открывать можно в любой момент (необратимо). Использовать — после открытия.
- Падение за борт: теряются ВСЕ открытые припасы (кроме `lifeRing`), закрытые остаются.
- Количество припасов на руках не ограничено.
- **Обмен/дарение/выбрасывание** — можно в любой момент **кроме фазы драки**. Включая чужой ход.
- Шантаж и подкуп — разрешены. Обещания **не обязательны к выполнению**.
- Чтобы использовать припас — он должен быть **открыт**.
- Одноразовые припасы помечены `singleUse: true`. После применения убираются из игры.

## 7. Фаза «День» — действия

Игроки совершают действия **по boat order, начиная с того, кто ближе к носу**, по одному на круг. Каждый игрок делает **ровно одно действие за день** (PDF: «День заканчивается, как только каждый игрок совершил действие, какое хотел.»). Союзничество в драке — **не считается** за действие.

Мёртвые и без сознания пропускаются.

Доступные действия:

1. **Погрести** (Row / `BEGIN_ROW`)
2. **Поменяться местами** (Offer swap / `OFFER_SWAP`)
3. **Ограбить** (Rob / `OFFER_ROB`)
4. **Способность Шкета — украсть** (только для Шкета)
5. **Применить специальный припас** (USE_FIRST_AID / USE_UMBRELLA / USE_FLARE)
6. **Бездельничать** (Skip / `SKIP_TURN`)

### 7.1 Погрести (Row)

1. `draw_count = 2`. Если у игрока есть открытые вёсла — `draw_count += число открытых вёсел`.
2. Игрок берёт `draw_count` карт навигации с верха колоды, смотрит секретно.
3. Игрок выбирает **0, 1 или 2** (или больше, если брал больше) карт, кладёт лицом вниз рядом с колодой навигации (станет пулом вечера — «карты от гребцов», анонимные).
4. Невыбранные карты убрать **под низ колоды навигации**.
5. Игрок получает 1 жетон усталости стороной **`rower`** («вёсла») вверх. Если уже был жетон усталости — нового не получает, остаётся один.
6. Вёсла остаются у игрока (передача — отдельная операция, не часть ROW).

**Модификатор веслом (дополнительно):**

- Если карта `oar` была закрыта — её можно раскрыть (теперь публичная), чтобы воспользоваться эффектом.
- С 1 веслом — 3 карты; с 2 — 4 карты.

> Карты, оставленные гребцами в пуле — **анонимны** (не известно, кто какую выбрал). Это важно для приватности.

### 7.2 Поменяться местами (Offer swap)

1. Игрок-инициатор выбирает целевую банку (с живым персонажем) — «хочу сесть на твоё место».
2. **Если занимающий целевую банку игрок без сознания или мёртв** — своп происходит немедленно (карты персонажей в лодке меняются местами).
3. **Если цель в сознании** — она отвечает:
   - **ACCEPT_SWAP**: банки меняются местами. Игрок может предложить компенсацию припасами, но это не обязывающее обещание. Порядок ходов на **ТЕКУЩИЙ день** остаётся прежним. Новый порядок применяется со следующего утра.
   - **REFUSE_SWAP**: инициатор **обязан** объявить драку. Отменить нельзя (правило стр. 11 PDF: «Если вы или вам объявили драку, отменить её уже нельзя»; «Нельзя передумать: «А, ты не согласен, ну тогда я сделаю что-нибудь другое».»). Переход в фазу драки — автоматический.

### 7.3 Ограбить (Rob)

Аналогично свопу, но цель — забрать одну карту припасов:

1. Объявить цель (живой персонаж).
2. **Если цель без сознания/мертва** — взять **одну** карту:
   - Любую открытую (на выбор грабителя), **ИЛИ**
   - Случайную из закрытых.
3. **Если цель в сознании** — она отвечает:
   - **ACCEPT_ROB**: цель сначала **перемешивает свои закрытые припасы**, затем грабитель выбирает любую открытую ИЛИ берёт наугад одну из закрытых.
   - **REFUSE_ROB**: автоматический переход в драку (то же правило, что для свопа).

PDF (стр. 10): грабитель выбирает (любую открытую ИЛИ случайную из закрытых); жертва только перемешивает.

### 7.4 Особая способность Шкета — воровать без драки

Шкет может **воровать** один раз за ход:

- **Только закрытые** карты.
- Шкет объявляет «ворую у тебя». После этого момент видимости фиксируется — жертва **не может открыть закрытые** карты для защиты.
- Жертва перемешивает свои закрытые припасы.
- Шкет тянет 1 случайную карту вслепую. Карта переходит к Шкету **в закрытую** (воровство не открывает её).
- **Один раз за ход.**

PDF: «Можно воровать один раз за ход. Вы можете выбрать: своровать в свой ход с помощью своей способности или сделать что-нибудь другое.»

⇒ Воровство **заменяет** обычное действие (как «бездельничать»), один раз за день. БЕЗ возможности драки.

### 7.5 Применить специальный припас (USE_SPECIAL_SUPPLY)

В свой ход можно применить **одно** из:

- **`USE_FIRST_AID(targetPlayerId)`** — снять 1 жетон ранения с себя или другого. Раскрыть и сбросить. Если персонаж был без сознания и ран стало меньше силы — он приходит в сознание.
- **`USE_UMBRELLA(targetPlayerId)`** — выложить открытой перед собой или другим персонажем. Многоразовая. Защищает от ранения за жажду, пока лежит открытой.
- **`USE_FLARE`** — открыть, использовать, сбросить. Посмотреть верхние 3 карты колоды навигации; учесть только чайки (за каждую — +жетон, за перечёркнутую — −жетон). Эти 3 карты убрать под низ колоды. Если стало 4 жетона — игра заканчивается, переход к подсчёту.

После USE_FIRST_AID / USE_FLARE карта припаса уходит из игры (одноразовые). Зонтик остаётся (он не одноразовый).

### 7.6 Бездельничать (Skip)

Ничего не делать, передать ход. Никаких жетонов.

### 7.7 Реактивные / в-любой-момент действия

В фазе «День», но не строго в свой ход:

- **Открыть закрытый припас** — можно в любой момент. Открытие необратимо.
- **Обмен/дарение/выбрасывание припасов** — в любой момент **кроме драки**. Включая чужой ход. Бартер с другими игроками. Никто не обязан выполнять обещания.
- **Использование одноразовых незапланированных предметов**: вода — только вечером после раскрытия карты навигации; приманка для акул — только вечером после раскрытия. Аптечка / зонтик / пистолет — только в свой ход днём.

> **Open question: можно ли отказаться от хода после объявления действия?**
> PDF (стр. 11): «Нельзя передумать.» — применимо к свопу/ограблению. Для ROW — двусмысленно: PDF (стр. 8) «Можете отказаться вообще от всех карт и все убрать под колоду». ⇒ После ROW можно вернуть все карты, но действие потрачено в любом случае.

## 8. Драка

**Триггер:** REFUSE_SWAP или REFUSE_ROB. Других триггеров нет.

Фаза драки — машина состояний:

```
SETUP_ATTACKER → SETUP_VICTIM → RECRUIT_ALLIES → REVEAL_WEAPONS → RESOLVE → APPLY_CONSEQUENCES
```

### 8.1 Алгоритм

1. **Атакующий объявляет драку.** Отмена невозможна. «Сдвигает вверх» свою карту персонажа (визуально — карта вне лодки).
2. **Жертва** «сдвигает вниз» свою карту.
3. **Обе стороны заявляют оружие:** открывают карты оружия из припасов (или используют уже открытые).
   - `club`/`hook`/`knife` дают `+weaponStrength` (значения с физических карт).
   - `oar` (весло) даёт +1 (как оружие). Несколько вёсел суммируются.
   - `flare` (сигнальный пистолет) можно потратить как одноразовое оружие (PDF стр. 12: «Сигнальный пистолет — тоже [оружие], но он одноразовый. Можете выстрелить в человека, а можете приберечь и выстрелить в небо»).
   - Закрытые карты в драке **не действуют** — союзник должен раскрыть оружие до объявления сил.
4. **Вербовка союзников:** обе стороны (начиная с атакующего, потом по boat order) могут звать других игроков в союзники.
   - Союзник «сдвигает» свою карту в сторону, на которой он. Может тоже задействовать своё открытое оружие.
   - Союзничество не обязательно — игрок может отказаться.
   - Вербовка может включать обещания припасов после драки (не обязывающие).
   - Участие союзником **НЕ считается действием в свой ход**.
5. **Союзники подтверждают участие** и заявляют своё оружие. С этого момента выйти из драки нельзя.
6. **Подсчёт сил:**
   ```
   side_strength(side) = Σ persona.strength
                      + Σ weapon.strengthBonus (для всех бойцов и их оружия на стороне)
   ```
   **Ранения НЕ уменьшают силу.** Сила фиксирована характеристикой персонажа.
7. **Разрешение:**
   - Если сила атакующего > силы защитника — победил атакующий, он получает желаемое (поменялся местами / забрал карту припасов).
   - Если сила атакующего ≤ силы защитника — победил защитник, он сохраняет всё.
   - **При равенстве сил побеждает защитник** (жертва).
8. **Последствия:**
   - Все участники (атакующий + защитник + все союзники) получают жетон усталости стороной **`fighter`** («силач») вверх.
   - Если у участника уже был жетон усталости в этот день (любой стороны) — новый не выдаётся (остаётся один).
   - Проигравшая сторона: каждый получает +1 жетон ранения.
   - Если у кого-то `wounds === strength` — он без сознания; `wounds > strength` — мёртв.
   - Если `flare` была использована как оружие — она уходит в сброс.

### 8.2 Дополнительные правила

- **Нельзя начать драку «просто так»** — только после отказа в свопе/ограблении.
- **Объявлена — не отменить.**
- **Союзник в драке не теряет своё действие** в свой ход.
- **Во время драки нельзя обмениваться припасами** — только обещаниями.
- **Никто не обязан выполнять обещания.**
- **Если в один день у игрока несколько драк** — новые жетоны усталости не выдаются.

> **Open question: значение `weaponStrength` у каждого оружия и `flare` как одноразового оружия.**
> В правилах не указаны конкретные числа. Нужно посмотреть на физических картах. Версия A фиксирует `hook: 4`, остальные TODO. Бонус от `flare` — обычно очень высокий (предположительно +10), TODO.

### 8.3 Без сознания и смерть

```
wounds >= strength → без сознания (unconscious)
wounds > strength  → смерть (dead)
```

- **Без сознания**: жив, ничего не может делать. Пропускается в раздаче припасов и в дневной очереди. **Может всё ещё страдать от жажды и падать за борт.** Может быть исцелён `firstAid` — приходит в сознание, если ран стало `< strength`.
- **Мёртв**: убирается из лодки. **Остаётся на банке** до конца игры (для подсчёта очков врагами/друзьями). Если умер от падения за борт без спасательного круга — карта персонажа и его припасы убираются полностью, банка сдвигается.

> **Open question: что происходит с припасами мёртвого игрока?**
> В PDF не указано явно.
> Версия A (в FAQ): если умер от падения за борт без круга — припасы убираются. Иначе остаются с трупом «на банке».
> Версия B: предлагаемая трактовка — припасы остаются на банке, другие могут грабить (ROB) тело. Альтернатива — уходят из игры.

## 9. Фаза «Вечер» — навигация

Запускается, когда все игроки в сознании сделали по одному действию.

### Процедура

1. **Выбор карты:** игрок в сознании, ближайший к корме, берёт стопку «карт от гребцов» (рубашкой вверх рядом с колодой), перемешивает, смотрит секретно, выбирает одну для розыгрыша. Остальные — под низ колоды.
2. **Если карт «от гребцов» нет** — взять верхнюю карту колоды навигации (принудительно).
3. **Компас:** если у этого игрока есть **открытый** `compass`, он берёт **+1** карту с верха колоды и добавляет к выбору.
   - Если карт «от гребцов» нет, то берёт 2 карты с верха.
4. **Раскрытие:** показать карту всем.
5. **Розыгрыш в строгом порядке:**

#### 5.a. Чайки (`seagulls`)

- Чайка → +1 жетон чайки на корму.
- Перечёркнутая → −1 жетон (минимум 0).
- Если стало 4 жетона — игра заканчивается, переход к подсчёту (остальные секции карты не разыгрываются).

#### 5.b. За борт (`overboard`)

Каждый персонаж, чьё имя над знаком «За бортом», падает за борт:

- Получает +1 жетон ранения (**Черпак** — не получает).
- Теряет все **открытые** припасы (кроме `lifeRing`, если он у него был открыт; `umbrella` тонет, как и все остальные открытые).
- **Возвращается в лодку.**
- **Открытый `lifeRing`** → персонаж НЕ падает, остаётся в лодке. Круг остаётся открытым.
- **Закрытый `lifeRing`** → игрок может открыть его в момент падения (реактивно через `USE_LIFE_RING_REACTIVE`), и тогда не падает. См. FAQ.
- **Без сознания / мёртвый, упавший за борт без `lifeRing`** — погибает (тело унесло течением), удаляется из игры со всеми припасами.
- Если в открытых упавшего была `sharkBait` — она автоматически срабатывает (см. ниже).

#### 5.c. Приманка для акул (`sharkBait`)

Любой игрок, у которого `sharkBait` в **открытых припасах** (и кто-то сейчас за бортом), **может** её использовать:

- Открыть приманку, показать всем, убрать из игры (одноразовая).
- Все, кто за бортом (включая владельца приманки, если он сам там), получают **+1 жетон ранения** дополнительно.
- Несколько `sharkBait` **не суммируются** (≤ +1 рана от акул).
- Если `sharkBait` лежала в открытых у того, кто упал за борт — она тоже срабатывает.

#### 5.d. Жажда (`thirst`)

Каждый персонаж, чьё имя под знаком «Жажда», страдает. Также по иконкам:

- **`rowers` (иконка вёсла)** → все, кто грёб сегодня (имеет жетон усталости стороной `rower`), страдают.
- **`fighters` (иконка силач)** → все, кто дрался сегодня (жетон `fighter`), страдают.
- Эффекты **суммируются**: если игрок и под «Жажда», и грёб — это 2 ранения.

Защита:

- **`water`** — раскрыть, показать, убрать из игры. Снимает 1 ранение от жажды у **себя или другого игрока** (одно использование = одно ранение спасено). Может быть закрытой — открывается прямо сейчас.
- **`umbrella`** (открытый) — защищает владельца от ранения за жажду, пока лежит открытым.

> **Open question: насколько защищает зонтик.**
> Правила: «Зонтик защищает от ранения за жажду». Не уточняется, защищает ли от **всех** ранений за жажду при текущей карте или только от **одного**.
> Предложенное решение для MVP: зонтик защищает от **всех** ранений за жажду в данном раунде (= при текущей карте навигации). Это даёт зонтику более понятную ценность.

- Если воды/зонтика нет — получить жетон(ы) ранения.
- **Без сознания не могут пить воду сами.** Если такому игроку выпала жажда, ему точно ранение. Один в сознании может **отдать ему свою воду** (PDF стр. 17: «кто-то в сознании может его напоить: показать всем свою карту с водой, сразу убрать её из игры»).
- Без сознания + жажда без помощи = +1 рана = смерть.

#### 5.e. Завершение карты

Карта убирается под низ колоды навигации.

#### 5.f. Конец дня

Жетоны усталости снимаются со всех персонажей. Жетоны ранений остаются.

### Особенности

- Без сознания + жажда = автоматическая рана (если водой не «напоили»). Для без-сознания 1 рана = смерть.
- За борт без сознания (или мёртвый) без `lifeRing` → удаление из игры. Игрок может всё ещё получать очки в конце за выживание друга и смерть врага.
- 4 чайки могут быть собраны как от карты навигации, так и от использования `flare` днём.

## 10. Цикл / конец игры

**Триггер конца игры:** на корме стало 4 жетона чаек.

Если игра не закончилась — начинается новый день с фазы «Утро».

**Если все умерли до 4 чаек** → море побеждает, подсчёт очков не производится.

## 11. Подсчёт очков

Игра кончается при 4 чайках. Все игроки (живые и мёртвые) считают очки. Карты друзей и врагов раскрываются.

### 11.1 Базовые очки за выживание

- **Жив** (`conscious` или `unconscious`): +`survivalBonus` своего персонажа.
- **Мёртв**: 0 за выживание.

### 11.2 Модификаторы выживания

- **Психопат** (сам себе враг): **0** очков за выживание.
- **Нарцисс** (сам себе друг): **×2** за выживание.
- **Психопат + нарцисс одновременно**: ×1 (обычное выживание; минусы не накапливаются).

### 11.3 Ценности

За карты `money`, `jewelry`, `painting` (открытые и закрытые) — добавить `pointValue` каждой карты.

Множители персонажей:

- **Миледи / Miledi**: украшения ×2.
- **Сноб / Snob**: картины ×2.
- **Капитан / Kapitan**: деньги ×2.

### 11.4 Друг и враг

- **Если лучший друг жив**: +его `survivalBonus`.
- **Если заклятый враг мёртв**: +его `strength`.
- **Если один и тот же персонаж — и друг, и враг (но не сам игрок)**:
  - Жив → +`survivalBonus` (бонус за выживание).
  - Мёртв → +`strength`.
  - Это правило **заменяет** пункты «друг» и «враг» по отдельности, не суммируется с ними.
- **Психопат-сам себе враг** дополнительно: **+3 очка** за каждого мёртвого персонажа в лодке, **кроме себя и своего лучшего друга**.

Псевдокод (из `game-rules.md`):

```ts
function score(player, allPlayers) {
  let pts = 0;
  const isAlive = !player.isDead;
  const character = player.role.character;
  const bestFriend = player.bestFriend;
  const worstEnemy = player.worstEnemy;
  const isNarcissist = bestFriend === character;
  const isPsycho = worstEnemy === character;

  // 1) Очки за выживание
  if (isAlive) {
    if (isPsycho && isNarcissist) pts += player.role.survivalBonus;
    else if (isPsycho)            pts += 0;
    else if (isNarcissist)        pts += 2 * player.role.survivalBonus;
    else                          pts += player.role.survivalBonus;
  }

  // 2) Очки за ценности (включая закрытые)
  for (const card of player.allSupplies) {
    if (card.type === 'money')        pts += card.valuePoints * (character === 'Kapitan' ? 2 : 1);
    else if (card.type === 'jewelry') pts += card.valuePoints * (character === 'Miledi'  ? 2 : 1);
    else if (card.type === 'painting')pts += card.valuePoints * (character === 'Snob'    ? 2 : 1);
  }

  // 3+4+5) Друг/враг (с учётом совпадения)
  if (bestFriend === worstEnemy && bestFriend !== character) {
    const target = allPlayers.find(p => p.role.character === bestFriend);
    pts += (target && !target.isDead ? target.role.survivalBonus : target.role.strength);
  } else {
    const friend = allPlayers.find(p => p.role.character === bestFriend);
    if (friend && bestFriend !== character && !friend.isDead) pts += friend.role.survivalBonus;
    const enemy = allPlayers.find(p => p.role.character === worstEnemy);
    if (enemy && worstEnemy !== character && enemy.isDead)  pts += enemy.role.strength;
  }

  // 6) Психопат-бонус
  if (isPsycho) {
    for (const p of allPlayers) {
      if (p === player) continue;
      if (p.role.character === bestFriend && !isNarcissist) continue;
      if (p.isDead) pts += 3;
    }
  }

  return pts;
}
```

### 11.5 Если никто не выжил

Море побеждает. Очки не считаются.

### 11.6 Победитель

Игрок с максимумом очков.

> **Open question: tiebreaker при равенстве очков в финале.**
> В правилах не оговорено.
> Предлагаемая трактовка: жив > мёртв; затем совместная победа.

## 12. FAQ / открытые вопросы

### 12.1 Компас

Работает только у игрока, ближайшего к корме **и в сознании**, и только если карта компаса открыта.

### 12.2 Гребцы не оставили карт

Кормовой берёт верхнюю карту колоды и разыгрывает. С компасом — две.

### 12.3 На карте навигации упомянут отсутствующий персонаж (5/4 игрока)

Игнорировать все упоминания.

### 12.4 Падение за борт без сознания

Не возвращается в лодку, погибает. Спасает спасательный круг в открытых припасах. Можно открыть круг «по пути в воду» — тоже считается.

### 12.5 Без сознания, но в спасательном круге, выпала «за борт»

Ничего не происходит, игрок остаётся в лодке. Для мёртвых — то же.

### 12.6 Может ли игрок использовать `water` за другого игрока без сознания

ДА. PDF (стр. 17): «кто-то в сознании может его напоить: показать всем свою карту с водой, сразу убрать её из игры». Это «дарение» воды + автоприменение.

### 12.7 Все игроки одновременно достигают 4 чаек через `flare`

Тривиально — игра заканчивается.

### 12.8 Sequencing внутри драки — кто первый объявляет союзников

PDF: атакующий зовёт, потом жертва, потом смотрят оружие. Реализовать как чёткий FSM (см. [`docs/state-machine.md`](./state-machine.md)).

## 13. Не описанные явно в правилах, но логически вытекающие edge cases

Эти случаи **необходимо обработать в reducer**:

1. **Шкет и единственная закрытая припаса у жертвы:** работает как обычно — Шкет тянет её.
2. **Шкет ворует у самого себя:** запрещено (действие на «другого игрока»).
3. **Шкет и количество ходов за день:** воровство **заменяет** обычное действие (как «бездельничать»), один раз за день.
4. **Несколько весел в драке:** каждое весло добавляет `strengthBonus`. Открытые вёсла суммируются.
5. **Союзник в драке использует своё закрытое оружие:** должен раскрыть до объявления сил. Закрытые карты в драке не действуют.
6. **Если все игроки мёртвы или без сознания:**
   - В фазе «Утро» нет игроков в сознании → пропустить фазу.
   - В Дне нет → перейти к Вечеру.
   - В Вечере нет — раскрыть верхнюю карту автоматически (никто не выбирает).
   - Если в результате никто не жив — игра кончается, море побеждает.
7. **Колода навигации опустела:** правила не оговаривают.
   > **Open question:** реализовать как «рециклинг» (все разыгранные карты обратно в колоду и перемешать) или просто заканчивать игру? Предлагаемое решение: рециклинг. Уточнить с игроками.
8. **Жертва ограбления и её закрытые припасы:** реализовать перемешивание перед выбором случайной (правило явное в PDF).
9. **Способность Шкета и согласие/драка:** Шкет может выбирать — украсть способностью (закрытую, без драки) ИЛИ ограбить (открытую/случайную с правом на драку). Это два разных action'а.
10. **Передача компаса/зонтика другому игроку через торг:** разрешено, как и любого припаса. Эффекты применяются по факту обладания.

## 14. Что выходит за рамки правил, но нужно для UX

- **Кто чей ход сейчас:** UI индикатор.
- **Лог действий:** что произошло за день (для пропустивших момент).
- **Подсветка валидных целей:** для свопа/ограбления подсвечиваются возможные цели.
- **Подтверждение деструктивных действий:** перед началом драки — «вы уверены?».
- **Уведомления:** «вас атакуют», «вас вербуют в союзники», «настал ваш ход».
