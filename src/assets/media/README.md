# Папка с картинками

Сюда складываются опциональные фото/иллюстрации для карт. Если файл с правильным
именем существует — UI его подгрузит. Если нет — отрендерится SVG/текстовый
fallback.

Подробные правила, размеры и соглашения о наименовании см. в [`docs/design-roadmap.md` §12](../../../docs/design-roadmap.md).

## Структура

```
characters/   ← портреты 6 персонажей (3:4, ~600×800)
supplies/     ← карты припасов (5:7, ~400×560)
navigation/   ← карты навигации (5:7)
backgrounds/  ← опциональные фоновые слои фаз (16:9, ~1920×1080)
```

## Нейминг

Имя файла **строго** равно id сущности в `src/game/constants.ts`. Расширение —
любое из `.webp`, `.png`, `.jpg`. Приоритет: webp > png > jpg.

Примеры:

- `characters/miledi.webp`
- `supplies/water.png`
- `navigation/seagull.jpg`
- `backgrounds/evening.webp`

## Как добавить новое фото

1. Положить файл с правильным именем в нужную подпапку.
2. Если dev-сервер уже запущен — HMR подхватит автоматически.
3. Если не уверен, что имя правильное, см.
   [`src/game/constants.ts`](../../game/constants.ts) (CHARACTERS, SUPPLY_TYPES).
